# **Month 1 — Linux + Networking + Git (foundation for DevOps)** 

# **Learn** 

- Linux: filesystem, permissions, users, processes, systemd, logs 

- Networking basics: DNS, ports, TCP/UDP, HTTP/HTTPS, SSH 

- Git + GitHub workflow (branches, PRs) 

# **Outcome** 

- Write a “DevOps basics” notes repo + simple troubleshooting runbook (check CPU/RAM/disk, tail logs, restart services). 

# **Month 2 — Scripting for Automation (Bash first, then Python/PowerShell)** 

# **Learn** 

- Bash scripting 

- Add **Python** basics for automation (appears in OLX / Toters nice-to-have) 

- basic **PowerShell** commands/scripts 

# **Outcome** 

- 8–12 automation scripts (log cleanup, backups, health checks, parsing logs, simple deployment helper scripts). 

# **Month 3 — AWS Core** 

# **Learn** 

- AWS fundamentals: IAM, EC2, VPC basics, Security Groups, Load Balancing basics 

- Basic AWS monitoring/logging: CloudWatch 

- Connect AWS knowledge to security basics (least privilege, access keys hygiene) 

# **Outcome** 

- Deploy a simple app to AWS EC2 (manual first) 

# **Month 4 — CI/CD (highest-frequency skill)** 

# **Learn** 

- PCI/CD system (GitHub Actions) 

- Pipelines: build → test → package → deploy 

- Environment variables and secrets handling in CI/CD 

# **Outcome** 

- A working pipeline that deploys to AWS (EC2 is enough). 

# **Month 5 — Containers + Delivery (Docker) + Databases basics** 

# **Learn** 

- Docker fundamentals + Dockerfile best practices 

- Docker Compose (multi-service) 

- Basic database operations and backup/restore concepts 

# **Outcome** 

- Containerize your app + database (Compose locally), then run the app on AWS using Docker. 

# **Month 6 — Security + Kubernetes** 

# **Learn** 

- DevSecOps basics: vulnerability/dependency scanning concepts, secrets management basics 

- AWS security focus: IAM policies, roles, least privilege 

- Kubernetes fundamentals 

# **Outcome** 

- Capstone: CI/CD pipeline + Docker deployment on AWS **plus** at least one security check step
